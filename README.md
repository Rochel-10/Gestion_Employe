#  Gestion des Employés - Django Project

##  Description

Application web de gestion des employés développée avec Django.  
Elle permet de gérer les employés avec les opérations CRUD :

- Créer un employé
- Lire la liste des employés
- Modifier un employé
- Supprimer un employé

---

##  Fonctionnalités

- Ajout d’employés
- Modification des informations
- Suppression d’employés
- Affichage dynamique de la liste
- Interface simple avec Tailwind CSS / DaisyUI

---

##  Technologies utilisées

- Python
- Django
- SQLite
- HTML / CSS
- Tailwind CSS
- DaisyUI
- Git & GitHub
